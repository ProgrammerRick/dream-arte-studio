# Dream Arte Studio — Identidade Visual

Este documento define as principais diretrizes visuais da Dream Arte Studio.

A identidade visual deve transmitir:

* Profissionalismo
* Criatividade
* Tecnologia
* Organização
* Modernidade
* Confiança
* Personalidade

A plataforma não deve parecer um WooCommerce genérico.

---

# 1. Conceito visual

A Dream Arte Studio é uma plataforma de serviços digitais.

O visual deve combinar:

```text
Premium
+
Moderno
+
Criativo
+
Tecnológico
+
Humano
```

O resultado deve parecer uma plataforma profissional própria, e não um conjunto de páginas padrão do WordPress.

---

# 2. Identidade da marca

Nome principal:

**Dream Arte Studio**

A marca deve utilizar o nome de forma consistente em:

* Header
* Footer
* Área do cliente
* Checkout quando aplicável
* E-mails
* Notificações
* Painel administrativo quando aplicável

Não utilizar nomes fictícios ou marcas diferentes.

---

# 3. Mascote

A Dream Arte possui um mascote próprio.

Arquivo principal atualmente utilizado:

```text
https://dreamarte.com.br/wp-content/uploads/2026/07/Mascote-da-Dream-Arte.png
```

O mascote poderá aparecer em:

* Header
* Home
* Cards
* Estados vazios
* Área do cliente
* Mensagens
* Banners
* Ilustrações
* Elementos promocionais

Quando utilizado em novas imagens, o personagem deverá manter sua identidade visual.

Evitar alterações desnecessárias em:

* Rosto
* Olhos
* Boca
* Formato da cabeça
* Corpo
* Características principais

Podem existir variações de:

* Pose
* Roupa
* Ação
* Cenário

desde que o personagem continue reconhecível como o mascote da Dream Arte.

---

# 4. Cores

A identidade principal utiliza tons de roxo/lilás combinados com branco e tons escuros.

Paleta de referência:

```text
Roxo principal: #7C3AED
Roxo neon: #A855F7
Lilás claro: #C084FC
Magenta: #E056FD
Ciano de destaque: #00F2FE
Verde de sucesso: #10B981

Fundo escuro principal: #06040D
Fundo escuro secundário: #09090B

Branco: #FAFAFA
Texto secundário: #A1A1AA
```

Essas cores são referências e podem ser ajustadas quando necessário para manter acessibilidade e harmonia visual.

---

# 5. Uso das cores

O roxo deve ser a principal cor de identidade.

Utilizar roxo/lilás em:

* Botões principais
* Links
* Destaques
* Ícones
* Bordas
* Gradientes
* Estados ativos
* Elementos decorativos

O branco deve ser utilizado para:

* Textos principais em fundos escuros
* Áreas claras
* Cards claros
* Contraste

O ciano e o magenta devem funcionar principalmente como cores de destaque.

Não utilizar todas as cores fortes ao mesmo tempo sem necessidade.

---

# 6. Fundos

A plataforma poderá utilizar dois estilos principais.

### Fundo escuro

Indicado para:

* Hero
* Seções de destaque
* Banners
* Áreas tecnológicas
* CTA

Referência:

```text
#06040D
#09090B
```

### Fundo claro

Indicado para:

* Serviços
* Configuradores
* Formulários
* Informações
* Áreas de leitura
* Conteúdo administrativo do cliente

O uso alternado de fundos escuros e claros pode criar ritmo visual.

---

# 7. Cards

Cards devem possuir aparência moderna e organizada.

Características possíveis:

* Bordas suaves
* Border radius
* Bordas discretas
* Sombras suaves
* Efeito glassmorphism quando adequado
* Pequenos detalhes em roxo
* Hover elegante

Evitar exagero em sombras, brilhos e efeitos.

---

# 8. Glassmorphism

O glassmorphism poderá ser utilizado em:

* Header
* Cards de destaque
* Menus
* Resumos
* Elementos sobre fundos escuros

Deve ser utilizado com moderação.

O conteúdo precisa continuar fácil de ler.

---

# 9. Tipografia

A tipografia deve ser moderna e limpa.

Fontes de referência:

```text
Plus Jakarta Sans
Sora
```

Podem ser utilizadas outras fontes equivalentes quando houver vantagem técnica ou de performance.

Priorizar:

* Legibilidade
* Hierarquia
* Espaçamento
* Consistência

---

# 10. Títulos

Os títulos devem possuir presença visual.

Utilizar:

* Tamanhos bem definidos
* Peso adequado
* Boa distância entre linhas
* Contraste suficiente

Evitar títulos gigantes que prejudiquem a experiência mobile.

---

# 11. Textos

A comunicação deve ser:

* Clara
* Direta
* Natural
* Profissional
* Fácil de entender

Evitar:

* Textos excessivamente técnicos
* Linguagem robótica
* Frases exageradas
* Promessas sem comprovação
* Jargões desnecessários

---

# 12. Botões

Os botões principais devem ser visualmente claros.

Exemplos:

```text
Começar projeto
Configurar serviço
Continuar
Adicionar ao projeto
Ir para pagamento
Solicitar orçamento
```

O botão principal deve possuir destaque visual suficiente para ser identificado rapidamente.

---

# 13. Microinterações

A plataforma deve possuir vida e movimento.

Podem ser utilizados:

* Hover
* Transições suaves
* Pequenas animações
* Fade
* Slide
* Scale
* Feedback de seleção
* Estados de carregamento

As animações devem melhorar a experiência.

Não utilizar animações apenas para enfeitar.

---

# 14. Configuradores

Os configuradores são uma das partes mais importantes da experiência.

Eles devem parecer uma ferramenta própria da Dream Arte Studio.

Evitar aparência de formulário padrão.

Utilizar:

* Cards de escolha
* Opções selecionáveis
* Estados ativos claros
* Resumo do projeto
* Preço atualizado
* Barra ou indicador de progresso quando fizer sentido

---

# 15. Seleção de opções

Quando uma opção estiver selecionada, isso deve ficar visualmente evidente.

Exemplo:

```text
┌───────────────────────────┐
│ ✓ Profissional            │
│                           │
│ R$ 79,90                  │
└───────────────────────────┘
```

A seleção não deve depender somente de uma pequena checkbox.

---

# 16. Resumo do projeto

O preço e o resumo devem permanecer fáceis de encontrar.

Exemplo:

```text
Seu projeto

Logo Profissional      R$ 79,90
Cartão                 R$ 15,00
Revisão adicional      R$ 10,00

Total                  R$ 104,90

[ Continuar ]
```

Em telas maiores, o resumo poderá ficar fixo na lateral.

No celular, deverá acompanhar a experiência sem ocupar espaço excessivo.

---

# 17. Preço

O preço deve ter destaque suficiente.

Exemplo:

```text
R$ 149,90
```

Quando houver preço inicial:

```text
A partir de R$ 99,90
```

Nunca apresentar um preço promocional falso ou criar descontos fictícios.

---

# 18. Página inicial

A Home deve apresentar rapidamente:

1. O que é a Dream Arte Studio
2. Serviços
3. Como funciona
4. Diferenciais
5. Exemplos/demonstrações
6. Segurança e pagamento
7. Perguntas frequentes
8. CTA

A página deve ter ritmo visual.

Evitar blocos enormes de texto.

---

# 19. Página de serviços

A página `/servicos/` deverá apresentar os serviços de maneira visual.

Cada serviço pode possuir:

* Ícone
* Imagem
* Nome
* Descrição curta
* Faixa de preço
* CTA

Exemplo:

```text
🎨 Logo
Crie uma identidade visual para sua marca.

A partir de R$ 49,90

[ Configurar ]
```

---

# 20. Páginas individuais

Cada serviço deverá possuir uma experiência própria.

Exemplo:

```text
/servicos/logo/
/servicos/musica-personalizada/
/servicos/landing-page/
```

A página deve apresentar:

* Introdução
* Benefícios
* O que está incluído
* Configurador
* Preço
* Prazo
* Informações importantes
* CTA

---

# 21. Favoritos

A página de favoritos deve ser visualmente simples.

O cliente poderá salvar serviços para consultar posteriormente.

Exemplo:

```text
Meus favoritos

🎨 Logo
🌐 Landing Page
📱 Posts
```

---

# 22. Meu Projeto

A área “Meu Projeto” deve funcionar como um espaço central de acompanhamento.

O cliente deve conseguir visualizar:

* Serviços selecionados
* Configurações
* Valores
* Status
* Próximas ações

---

# 23. Área do cliente

A área do cliente deve parecer um painel próprio.

Evitar simplesmente mostrar a interface padrão do WooCommerce.

Elementos possíveis:

```text
Olá, Luiz!

Projetos
Pedidos
Arquivos
Revisões
Favoritos
Dados da conta
```

---

# 24. Status visual

Os status devem ser fáceis de entender.

Exemplos:

🟡 Aguardando pagamento

🔵 Pagamento aprovado

🟣 Em produção

🟠 Aguardando você

🔄 Em revisão

🟢 Entregue

⚫ Cancelado

As cores devem sempre vir acompanhadas de texto.

Não depender somente da cor para comunicar informação.

---

# 25. Entregas

A página de entrega deve transmitir sensação de conclusão.

Exemplo:

```text
Seu projeto está pronto! 🎉

Logo Profissional

Entrega final

[ Baixar arquivo ]

Versão final
PNG · JPG
```

Arquivos privados devem continuar protegidos pelo sistema.

---

# 26. Responsividade

Mobile deve ser tratado como prioridade.

O sistema deverá funcionar corretamente em:

* 320px
* 360px
* 375px
* 390px
* 414px
* Tablets
* Desktop

Não criar uma interface desktop e simplesmente diminuir tudo no celular.

O layout mobile deve ser pensado separadamente quando necessário.

---

# 27. Espaçamento

Utilizar espaçamento consistente.

Evitar:

* Elementos colados
* Seções apertadas
* Espaços enormes sem motivo
* Alinhamentos inconsistentes

A interface deve transmitir organização.

---

# 28. Ícones

Preferir ícones simples e modernos.

Podem ser utilizados:

* SVG
* Lucide
* Font Awesome
* Ícones próprios

Evitar excesso de estilos diferentes.

---

# 29. Imagens

As imagens devem possuir qualidade suficiente para parecerem profissionais.

Priorizar:

* Imagens relevantes
* Boa composição
* Boa resolução
* Compressão adequada
* WebP quando apropriado

Evitar imagens genéricas sem relação com o serviço.

---

# 30. Freepik e Envato

A Dream Arte Studio poderá utilizar recursos licenciados do Freepik e Envato Elements durante a produção.

Porém:

* Respeitar os termos da licença.
* Não prometer exclusividade quando ela não existir.
* Não apresentar um recurso de terceiros como criação exclusiva quando isso não for verdade.
* Não redistribuir arquivos originais de forma incompatível com a licença.
* Entregar somente os arquivos e formatos permitidos.
* Verificar as condições de uso de cada recurso quando necessário.

---

# 31. Portfólio

O portfólio deve apresentar trabalhos reais ou demonstrações claramente identificadas.

Não inventar:

* Clientes
* Avaliações
* Quantidade de projetos
* Resultados
* Faturamento
* Percentuais de conversão
* Depoimentos

Se uma demonstração for fictícia, deixar claro que é uma demonstração.

---

# 32. Prova social

Somente utilizar números e depoimentos reais quando existirem.

Evitar frases como:

```text
+180 projetos entregues
4.9/5 com 112 avaliações
+340% de vendas
99% de satisfação
```

quando esses dados não tiverem comprovação.

A plataforma deve transmitir confiança através da apresentação, não de números inventados.

---

# 33. Linguagem comercial

A comunicação pode ser persuasiva, mas deve ser honesta.

Evitar promessas absolutas como:

* “Vai aumentar suas vendas”
* “Garantimos resultados”
* “O melhor site do mercado”
* “Resultados garantidos”

Preferir apresentar benefícios concretos.

---

# 34. Animações

As animações devem ser:

* Suaves
* Rápidas
* Elegantes
* Responsivas

Evitar:

* Excesso de movimento
* Animações lentas
* Elementos piscando
* Efeitos que dificultem leitura
* Efeitos que prejudiquem performance

---

# 35. Acessibilidade

A interface deve considerar:

* Contraste
* Tamanho de texto
* Foco de teclado
* Labels
* Alt text
* Botões identificáveis
* Estados de erro claros

Não comunicar informações importantes somente através de cores.

---

# 36. Consistência

Componentes semelhantes devem possuir aparência semelhante.

Exemplo:

Todos os botões principais devem seguir a mesma linguagem visual.

Todos os cards de serviço devem possuir estrutura semelhante.

Todos os estados de status devem seguir o mesmo padrão.

---

# 37. WooCommerce visual

O WooCommerce poderá fornecer a infraestrutura comercial.

Porém, visualmente:

**A plataforma não deve parecer uma loja WooCommerce padrão.**

Checkout, carrinho e conta devem ser estilizados para combinar com a identidade da Dream Arte Studio sempre que tecnicamente possível.

---

# 38. Elementor Free

A identidade visual deverá funcionar com Elementor Free.

Quando uma funcionalidade visual não existir no Elementor Free, poderá ser criada utilizando:

* HTML
* CSS
* JavaScript
* Recursos do WordPress
* Dream Arte Studio Core

Não assumir que Elementor Pro está disponível.

---

# 39. Experiência premium

“Premium” não significa adicionar efeitos em tudo.

Uma experiência premium deve transmitir:

```text
Boa hierarquia
+
Bom espaçamento
+
Tipografia consistente
+
Animações discretas
+
Boa usabilidade
+
Detalhes bem executados
```

---

# 40. Regra final de design

Antes de considerar uma página pronta, verificar:

* Está organizada?
* Funciona bem no celular?
* O usuário entende o que fazer?
* O preço está claro?
* Os botões estão claros?
* Os textos são naturais?
* A identidade Dream Arte está presente?
* Existem animações suficientes para dar vida sem exagerar?
* O layout parece uma plataforma própria?
* Existe algum elemento genérico ou mal alinhado?
* Alguma informação foi inventada?
* Alguma promessa não pode ser comprovada?

Se a resposta indicar problemas, corrigir antes de considerar a página concluída.

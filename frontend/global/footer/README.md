# Footer

Componente global de rodapé da Dream Arte Studio.

## Objetivo

Criar um footer moderno, organizado e responsivo, utilizado nas páginas da plataforma.

## Elementos

- Logo da Dream Arte Studio
- Breve apresentação da plataforma
- Links de navegação
- Serviços
- Área do cliente
- Favoritos
- Meu Projeto
- Contato
- Redes sociais, quando houver links oficiais definidos
- Informações legais
- Direitos autorais

## Requisitos

- Compatível com Elementor Free.
- Responsivo para desktop, tablet e celular.
- Visual consistente com a identidade da Dream Arte Studio.
- Não parecer um footer padrão do WooCommerce.
- Não utilizar informações, contatos ou links fictícios.
- Não inventar redes sociais ou dados que ainda não foram definidos.
- CSS e JavaScript devem ser isolados para evitar conflitos.

## Estrutura futura

O componente poderá ser dividido em:

- HTML
- CSS
- JavaScript

Cada parte será desenvolvida separadamente quando o código real for criado.

# Header

Componente global de cabeçalho da Dream Arte Studio.

## Objetivo

Criar um header premium, moderno, responsivo e reutilizável em todas as páginas da plataforma.

## Elementos

- Logo da Dream Arte Studio
- Mascote da marca
- Navegação principal
- Serviços
- Favoritos
- Meu Projeto
- Minha Conta
- Indicador de novos projetos
- Menu mobile

## Requisitos

- Compatível com Elementor Free.
- Responsivo para desktop, tablet e celular.
- Visual premium e moderno.
- Não parecer um header padrão do WooCommerce.
- Utilizar a identidade visual definida no projeto.
- Não utilizar informações ou links fictícios.
- Evitar dependências desnecessárias.
- CSS e JavaScript devem ser isolados para evitar conflitos com outras partes do site.

## Estrutura futura

O componente poderá ser dividido em:

- HTML
- CSS
- JavaScript

Cada parte deverá ser desenvolvida separadamente quando o código real for criado.

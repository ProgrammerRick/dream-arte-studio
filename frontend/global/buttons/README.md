# Buttons

Componente global de botões da Dream Arte Studio.

## Objetivo

Criar um padrão visual consistente para os botões utilizados em toda a plataforma.

## Tipos

O sistema poderá possuir diferentes variações, conforme a função do botão:

- Primário
- Secundário
- Terciário
- Ghost
- Destrutivo
- Botão de ação rápida

## Exemplos de uso

- Configurar pedido
- Comprar agora
- Ver serviço
- Continuar
- Voltar
- Finalizar pedido
- Solicitar orçamento
- Adicionar aos favoritos

## Requisitos

- Compatível com Elementor Free.
- Responsivo.
- Acessível e fácil de identificar.
- Possuir estados de hover, foco, ativo e desabilitado quando necessário.
- Manter a identidade visual da Dream Arte Studio.
- Não utilizar estilos diferentes sem necessidade.
- CSS deve ser organizado para evitar conflitos com outros componentes.

## Estrutura futura

O componente poderá conter:

- HTML
- CSS
- JavaScript, somente quando necessário.

Os estilos deverão ser reutilizáveis entre as páginas da plataforma.

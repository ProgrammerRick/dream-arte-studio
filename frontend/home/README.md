# Home

Página inicial da Dream Arte Studio.

## Objetivo

Apresentar a plataforma, seus principais serviços e o funcionamento dos pedidos de forma clara, moderna e visualmente atraente.

A Home deve levar o visitante naturalmente para a escolha de um serviço.

## Estrutura

A Home será dividida em componentes independentes:

1. Header
2. Hero
3. Serviços em destaque
4. Diferenciais
5. Como funciona
6. Portfólio
7. FAQ
8. CTA final
9. Footer

## Hero

O Hero deverá apresentar:

- proposta principal da Dream Arte Studio;
- breve explicação;
- botão principal para conhecer os serviços;
- botão secundário quando fizer sentido;
- elemento visual relacionado à identidade da marca.

Não utilizar estatísticas, avaliações, quantidade de clientes ou resultados que não tenham sido comprovados.

## Serviços em destaque

Apresentar os principais serviços da plataforma de forma visual e organizada.

Cada serviço deverá possuir:

- nome;
- descrição curta;
- imagem ou elemento visual;
- preço inicial quando apropriado;
- botão para acessar o serviço.

## Diferenciais

Apresentar características reais da plataforma, como:

- configuração personalizada;
- pagamento online;
- acompanhamento do pedido;
- entrega digital;
- atendimento.

Não criar diferenciais fictícios.

## Como funciona

Explicar o processo de forma simples:

1. Escolha o serviço.
2. Configure o que precisa.
3. Confira o valor.
4. Faça o pagamento.
5. Acompanhe o projeto.
6. Receba a entrega.

## Portfólio

Área destinada à apresentação de trabalhos reais ou exemplos autorizados.

Não utilizar trabalhos de terceiros como se fossem projetos da Dream Arte Studio.

Quando forem utilizados recursos de Freepik, Envato Elements ou outras bibliotecas, respeitar suas respectivas licenças.

## FAQ

Responder dúvidas frequentes sobre:

- serviços;
- preços;
- prazos;
- pagamento;
- revisões;
- arquivos;
- domínio e hospedagem;
- pedidos personalizados.

As respostas devem corresponder às regras reais da plataforma.

## CTA

A Home deverá terminar com uma chamada clara para iniciar um pedido.

Exemplo de ação:

**Escolher um serviço**

## Elementor Free

A Home deve ser construída de forma compatível com Elementor Free.

Cada seção deverá poder ser desenvolvida como componente independente.

Evitar criar uma única estrutura HTML gigante.

## Responsividade

Todas as seções devem funcionar corretamente em:

- celular;
- tablet;
- desktop.

## Animações

Utilizar animações com moderação.

O objetivo é deixar a página viva e premium sem prejudicar:

- velocidade;
- legibilidade;
- navegação;
- acessibilidade.

## Regra de desenvolvimento

A Home será desenvolvida seção por seção.

Cada componente deverá ser aprovado antes da criação do próximo.

O código deverá permanecer separado em HTML, CSS e JavaScript quando necessário.
